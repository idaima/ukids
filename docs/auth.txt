1.短信验证码
https://fastapi.ukids.cn/ucapp/sms

curl -H "Cache-Control: public, max-age=3600" -H "format: JSON" -H "channel: anp6" -H "ver: 5.0.3" -H "verCode: 503" -H "xfrom: 1" -H "hos: Android16" -H "token: " -H "mode: parents" -H "dtp: phone" -H "chdAgeDays: -1" -H "Content-Type: application/json; charset=UTF-8" -H "Host: fastapi.ukids.cn" -H "User-Agent: okhttp/3.12.8" --data-binary "{\"mobile\":\"13800000000\",\"type\":\"1\"}" "https://fastapi.ukids.cn/ucapp/sms"

接口返回示例：
{
	"success": true,
	"data": {
		"msg": "验证码已发送"
	},
	"error": null,
	"page": null,
	"curtime": 1767168956810
}
